나레이션 생성기

대본을 붙여 넣으면 쇼츠용 나레이션 음성 파일이 나오는 개인용 페이지. 음성은 ElevenLabs·Typecast·구글 Gemini의 API가 만들고, 이 페이지는 주문서를 보내고 결과를 받아옵니다.

API 키는 이 브라우저 안에만 저장됩니다. 이 페이지에는 서버가 없어서 키가 운영자에게도 가지 않습니다. 공용 PC에서는 "저장" 체크를 끄고 쓰세요. 글자 수만큼 선택한 회사의 크레딧이나 요금이 나갑니다(아래 "요금과 준비" 참고).

        요금과 준비

        숫자는 2026-09-19 기준 각 회사 공식 요금 페이지 값입니다. 1분 환산은 "분당 약 360자(공백 제외)" 가정으로 계산한 것이라 실제와 다를 수 있어요.

        모델회사요금비고
        키 발급과 결제 준비
        1. ElevenLabs — 설정 → API Keys에서 발급. 무료 플랜(월 1만 크레딧)은 상업 이용 불가·출처 표기 필수라 수익화 쇼츠에는 Starter(월 $6)부터 쓰세요. 목소리 설계(Voice Design)는 무료 플랜에도 있고, 내 목소리 즉석 복제는 Starter부터입니다.
        2. Typecast — API 콘솔에서 발급. 웹 에디터 구독과 API 플랜은 별개입니다. 무료 API 플랜(월 1.5만 크레딧)도 상업 이용 불가·출처 표기 필수, Lite(월 $15)부터 상업 이용 가능.
        3. 구글 Gemini API — AI Studio에서 키 발급. 영상 생성기와 같은 키를 씁니다. TTS는 무료 등급에서도 되지만, 무료 등급 입력은 구글 제품 개선에 쓰일 수 있어요. 결과는 WAV로 나옵니다.
        키 보호와 지출 상한
        • 이 페이지는 키를 브라우저 저장소(localStorage)에만 둡니다. 같은 브라우저에서 같은 주소의 다른 스크립트가 읽을 수 있으므로, 이 사이트에 다른 사람이 코드를 올릴 수 없게 저장소 권한을 관리하세요.
        • ElevenLabs: 키를 만들 때 권한을 "Text to Speech·Voices"로 좁히고, 크레딧 한도(custom credit quota)를 걸어 두면 새더라도 피해가 그 안에서 끝납니다.
        • Typecast: 계정당 키 1개가 기본이고 도메인 제한 기능은 없습니다. 키가 샌 것 같으면 콘솔에서 새로 발급하세요.
        • 구글: 2026년 5월 28일 이후 발급되는 키는 IP 주소 제한만 걸 수 있습니다. Google Cloud 결제 콘솔에서 예산 알림을 걸어 두세요.
        • 세 회사 모두 공식 안내는 "키를 브라우저에 두지 말라"입니다. 이 페이지는 본인만 쓰는 용도로 두세요. 브라우저에서 직접 호출이 되는 것은 2026-09-19에 실측한 결과이고, 회사가 막으면 언제든 안 될 수 있습니다.
        원하는 말투에 맞추는 요령
        • 속도: 분당 340음절쯤 되는 속도는 ElevenLabs에서는 파라미터(Flash·Multilingual 최대 1.2배)만으로 안 나옵니다. 원래 빠른 목소리를 고르거나 설명문에 "extremely fast"를 넣어 설계하세요. v3는 속도 슬라이더가 없고 태그로만 유도됩니다. Typecast는 속도 2.0배까지 숫자로 됩니다. 구글은 [very fast] 태그와 연출 지시로만 됩니다.
        • 감탄사·웃음: ElevenLabs v3와 구글은 대본 안에 [laughs] [sighs] [gasp] 같은 영어 태그를 넣습니다. Typecast는 태그가 없고 감정 프리셋·강도로 조절합니다.
        • 질문형 어미: 어느 서비스도 억양을 직접 조절하는 수단이 없습니다. 물음표를 꼭 붙이고, 구글은 연출 지시에 "questions rise sharply at the end"를 둡니다.
        • 비속어: 세 회사 모두 비속어 자체를 금지하는 조항은 없지만, 구글은 안전 필터에 걸려 거절될 수 있고 Typecast는 음란·성인 표현 생성을 금지합니다. 거절되면 그 부분만 순화해 다시 시도하세요.
        • 역할극: 대본 위 "역할극" 탭을 누르고 줄마다 이름: 대사 로 적으면 배역마다 목소리를 고를 수 있습니다. ElevenLabs v3는 대화 전용 API로 한 번에(한 요청 2,000자·목소리 10개), Typecast는 줄마다 목소리를 바꿔 한 파일로(한 요청 2,000자·50조각), 구글은 2명까지 한 요청으로 만듭니다. 그 밖의 경우는 줄마다 따로 만들어 이어 붙입니다.
        • ElevenLabs Flash v2.5는 숫자·날짜를 기대대로 읽지 않을 수 있습니다. 숫자는 한글로 풀어 쓰세요. 긴 대본은 이 페이지가 모델 한도(v3 5,000자 · Flash 40,000자 · Multilingual 10,000자 · Typecast 2,000자)씩 문장 단위로 나눠 보내고 이어 붙입니다.
