영상 생성기

텍스트나 이미지 한 장으로 짧은 영상을 만드는 개인용 페이지. 영상은 구글·fal.ai·Higgsfield의 API가 만들고, 이 페이지는 주문서를 보내고 결과를 받아옵니다.

API 키는 이 브라우저 안에만 저장됩니다. 이 페이지에는 서버가 없어서 키가 운영자에게도 가지 않습니다. 공용 PC에서는 "저장" 체크를 끄고 쓰세요. 영상 1편마다 선택한 회사에 요금이 붙습니다(아래 "요금과 준비" 참고).

    키 발급과 결제 준비
    1. 구글 Gemini API — AI Studio에서 키 발급. 영상 생성은 무료 티어에서 안 되므로 AI Studio에서 결제(유료 티어)를 켜야 합니다. 만든 영상은 구글 서버에 2일만 남으니 바로 내려받으세요.
    2. fal.ai — 대시보드에서 키 발급 후 크레딧을 선불로 충전합니다. 가입 무료 크레딧은 API로는 못 씁니다. 결과 영상 링크는 7일간 공개 링크로 남습니다.
    3. Higgsfield API — 개발자 콘솔에서 별도 API 계정을 만들고 잔액을 충전(최소 $5)하면 KEY_ID:KEY_SECRET 형태의 키가 나옵니다. 사이트 구독(Plus 등)과는 별개 지갑입니다. 결과는 7일 이상 보관됩니다.
    키 보호와 지출 상한
    • 이 페이지는 키를 브라우저 저장소(localStorage)에만 둡니다. 같은 브라우저에서 같은 주소의 다른 스크립트가 읽을 수 있으므로, 이 사이트에 다른 사람이 코드를 올릴 수 없게 저장소 권한을 관리하세요.
    • 구글: 2026년 5월 28일 이후 발급되는 키는 "auth key"이고 IP 주소 제한만 걸 수 있어서, 특정 사이트에만 묶어 두는 설정은 안 됩니다. 대신 Google Cloud 결제 콘솔에서 예산 알림을 걸어 두세요. 구글 공식 안내는 키를 웹 앱에 넣지 말라는 것이므로, 이 페이지는 본인만 쓰는 용도로 두세요.
    • fal.ai · Higgsfield: 선불 충전이라 충전한 만큼만 나갑니다. 키가 새면 잔액까지만 피해가 갑니다. 새 키를 발급하고 옛 키를 지우면 됩니다.
    • 키가 노출된 것 같으면 해당 사이트에서 즉시 키를 삭제하고 새로 발급하세요.
