1. 운영 주체

개인 운영자. 연락처: sjj960219@gmail.com

2. 접근하는 구글 사용자 데이터

이 앱은 운영자 본인의 구글 계정에 대해 다음 권한을 사용합니다.

  • youtube.upload — 운영자 본인 채널에 영상을 업로드합니다.
  • youtube.force-ssl — 업로드한 영상의 제목·설명·태그 등 메타데이터를 설정하고, 본인 채널의 댓글을 읽고 작성합니다.
  • youtube.readonly — 본인 채널의 영상 목록을 조회합니다.
  • yt-analytics.readonly — 본인 채널의 조회수 등 통계를 조회합니다.

3. 데이터의 저장 위치

인증 토큰은 운영자 본인 PC의 로컬 파일에만 저장됩니다. 외부 서버로 전송되지 않으며, 제3자와 공유하거나 판매하지 않습니다. 이 앱은 자체 서버나 데이터베이스를 운영하지 않습니다.

4. 수집하는 타인의 정보

없습니다. 이 앱은 운영자 본인 외의 사용자가 없으며, 타인의 개인정보를 수집·저장·처리하지 않습니다.

5. 이 웹사이트에 대하여

이 웹사이트는 쿠키, 애널리틱스, 광고, 추적 스크립트를 일절 사용하지 않으며, 방문자의 어떠한 정보도 수집하지 않습니다.

English summary

Mallangnus Uploader is a personal script run on the operator's own computer to upload videos to the operator's own YouTube channel and read that channel's statistics. It has no users other than the operator.

OAuth tokens are stored only in a local file on the operator's computer. Nothing is transmitted to any external server, and no data is shared with or sold to third parties. This app operates no server or database of its own, and collects no information from anyone else.

This website uses no cookies, analytics, advertising, or tracking scripts, and collects no visitor information.

This app's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
